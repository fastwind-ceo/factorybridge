# STEP 013 — Frontend Customer Portal

Implemented customer-facing UI shell for FactoryBridge MVP:

- public landing page;
- login/register pages;
- customer dashboard;
- RFQ list;
- RFQ creation wizard;
- RFQ detail page with AI review, files, timeline and quote comparison;
- quotes page;
- landed cost customer-facing view;
- notifications page;
- shared design system CSS;
- shared components: AppShell, MetricCard, StatusBadge, RFQTable;
- API client placeholders connected to `NEXT_PUBLIC_API_URL`.

The frontend currently uses mock data where backend integration will be completed during the full workflow integration step. The pages are structured around the API contracts from planning and the endpoints implemented in backend steps 001–012.
