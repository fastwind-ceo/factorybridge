# Pilot Operations Checklist

## Before Pilot
- [ ] Production/staging server prepared
- [ ] Domain/DNS configured
- [ ] HTTPS configured
- [ ] Admin account created
- [ ] Operator account created
- [ ] Backup script tested
- [ ] Storage configured
- [ ] SMTP/notifications configured or disabled safely
- [ ] Pilot suppliers registered
- [ ] Pilot customers registered

## During Pilot
- [ ] Every RFQ reviewed by operator
- [ ] AI output checked by human
- [ ] Supplier access limited to invited RFQs
- [ ] Sensitive files protected
- [ ] Quotes checked before customer presentation
- [ ] Landed cost reviewed manually
- [ ] Order events maintained

## After Pilot
- [ ] Collect customer feedback
- [ ] Collect supplier feedback
- [ ] Review audit logs
- [ ] Review RFQ completeness issues
- [ ] Review supplier response times
- [ ] Update roadmap
- [ ] Prepare next release scope
