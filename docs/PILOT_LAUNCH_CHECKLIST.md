# FactoryBridge Pilot Launch Checklist

## Infrastructure

- VPS prepared
- Docker installed
- Domain configured
- SSL enabled
- Firewall configured

## Backend

- Database migrations applied
- Health endpoint operational
- Authentication flow operational
- RFQ endpoints operational

## Frontend

- Landing page operational
- Login and registration operational
- Dashboard routes operational
- Supplier and admin pages operational

## Operations

- Demo accounts created
- Smoke tests executed
- Backup strategy prepared
- Monitoring enabled

## Go-live decision

Pilot launch allowed only after all checks are green.
